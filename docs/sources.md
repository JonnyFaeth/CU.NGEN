# Reference sources

These are reference links, not claims that CU has implemented or validated the referenced systems. Pin exact revisions before selecting components or copying licensed assets.

- [LeRobot repository](https://github.com/huggingface/lerobot): upstream software, licensing, supported interfaces, and contribution guidance.
- [Bring Your Own Hardware](https://huggingface.co/docs/lerobot/integrate_hardware): robot integration interface and motor-bus guidance.
- [HopeJR](https://github.com/TheRobotStudio/HOPEJr): open humanoid development reference; not the selected CU design.
- [LeRobot HopeJR documentation](https://huggingface.co/docs/lerobot/hope_jr): arm/hand workflow reference; does not establish CU walking or gap-crossing capability.
- [Schmalz suction-cup technical data](https://www.schmalz.co.jp/en-jp/support/know-how/vacuum-knowledge/the-vacuum-system-and-its-components/vacuum-suction-cups/technical-data-of-suction-cups): vacuum holding-force considerations.
- [Piab suction-cup valves](https://www.piab.com/en-us/suction-cups-and-soft-grippers/accessories-for-suction-cups/suction-cup-valves): examples of vacuum isolation components; no component purchase selected.
