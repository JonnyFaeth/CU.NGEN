# CU LeRobot

A proposed small desktop cleaning robot with a wheeled humanoid form, arms, and a head, designed for integration with the [LeRobot ecosystem](https://github.com/huggingface/lerobot).

The intended user has no workshop or 3D printer. Future kits should include manufactured structures, required tools, and instructions. CU may also offer assembly and testing.

The long-term objective is to clean while the user is away and return to a dock when the battery is low. Neither unattended operation nor self-charging has been demonstrated.

- [Requirements and open questions](requirements.md)
- [Validation plan](validation.md)
- [Source references](../../docs/sources.md)

No robot has been built or tested under this project. No validated bill of materials, CAD release, motor selection, price, or LeRobot adapter exists yet. Earlier planning around a walking humanoid has been superseded by the accepted wheeled direction.
